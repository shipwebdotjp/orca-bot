Orca Bot

Orca Bot は、Gmail と連携し、メールの取得・整理・要約などの定型作業を自動化する個人向けのツールです。

できること

  • Gmail のメールを取得し、内容の要約や分類を行う
  • 必要なメールの抽出、ラベルの付与、通知などの自動処理
  • 日々の受信トレイの確認作業の省力化

Google アカウントとの連携について

Orca Bot は、利用者本人の同意に基づいて Google アカウントに接続し、Gmail API を通じてメールの読み取りおよび管理を行います。取得したデータは、上記の機能を提供する目的にのみ利用します。

Google API から取得した情報の取り扱いについては、 プライバシーポリシー をご確認ください。Orca Bot による Google API から取得した情報の他のアプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に準拠します。

English

Orca Bot is a personal automation tool that connects to Gmail to read, organize and summarize email messages on behalf of its owner. It accesses Google user data only with the user's consent and uses it solely to provide these features. See the Privacy Policy for details. Orca Bot's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
