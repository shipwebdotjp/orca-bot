プライバシーポリシー

制定日: 2026年11月25日 ／ 最終更新日: 2026年11月25日

Orca Bot（以下「本ツール」）は、本ツールの利用者（以下「利用者」）のプライバシーを尊重し、個人情報および Google ユーザーデータを適切に取り扱います。本プライバシーポリシーは、本ツールが取得する情報、その利用目的、 保存方法、第三者への提供、および利用者が行える削除・撤回の方法について説明します。

1. 取得する情報

本ツールは、利用者が Google アカウントとの連携を許可した場合に限り、以下の情報を取得します。

  • Google アカウント情報：メールアドレス、アカウント識別子、プロフィール情報（氏名・アイコン画像など、 連携時に取得できる範囲）
  • Gmail のデータ：メッセージの本文、件名、送信者・受信者、送受信日時、スレッド、ラベル、 添付ファイルのファイル名および種類などのメタデータ
  • 認証情報：OAuth 2.0 のアクセストークンおよびリフレッシュトークン
  • 動作ログ：本ツールの実行履歴、処理結果、エラー情報

本ツールは、Gmail のデータのうち、上記の機能を提供するために必要な範囲の情報のみを取得します。パスワードを取得・保存することはありません。

2. 利用目的

取得した情報は、以下の目的にのみ利用します。

  • メールの取得、要約、分類、抽出、ラベル付与などの自動処理
  • 利用者への通知および処理結果の表示
  • 本ツールの動作の維持、不具合の調査および改善
  • 利用者からの問い合わせへの対応

取得した情報を、広告の配信、プロファイリング、データブローカーへの販売、その他これらの目的と無関係な用途に利用することはありません。

3. 外部サービスへの送信

本ツールは、メールの要約・分類・返信文の生成などの機能を実現するため、 メール本文の全部または一部を、運営者が利用する外部の AI サービス（大規模言語モデル API）に送信する場合があります。

  • 送信先は、運営者が契約する API 提供事業者（例：OpenAI）です。
  • 送信する情報は、目的の処理に必要な範囲に限定します。不要なメールや添付ファイルの内容を送信することはありません。
  • 送信先事業者におけるデータの取り扱いは、当該事業者の利用規約およびプライバシーポリシーに従います。運営者は、API 経由で送信したデータがモデルの学習に使用されない設定・契約を選択するよう努めます。
  • 上記の委託先を除き、利用者の同意なく Google ユーザーデータを第三者に提供することはありません。

4. 保存と安全管理

  • 認証情報（トークン）は、運営者が管理する端末またはサーバ上に保存し、第三者による不正アクセスを防ぐ措置を講じます。
  • メール本文などのデータは、処理に必要な期間のみ一時的に保持し、処理の完了後は速やかに削除します。恒久的なメールデータベースの構築は行いません。
  • 動作ログは、不具合の調査およびセキュリティ確保に必要な期間のみ保存し、その後削除します。

5. 第三者提供

本ツールは、法令に基づく場合、または利用者の明示的な同意がある場合を除き、取得した情報を第三者に提供しません。 前項に定める外部 AI サービスへの送信は、本ツールの機能提供に必要な委託として行うものです。

6. 利用者によるアクセスの停止・削除

利用者は、以下の方法で本ツールによるデータへのアクセスを停止し、削除を求めることができます。

  • Google アカウントの「サードパーティのアプリとサービス」 から、本ツールのアクセス権を削除する。これにより、以後のデータ取得は行われなくなります。
  • 下記の連絡先までご連絡いただくことで、保存されている認証情報およびログの削除を行います。

7. Cookie およびアクセス解析

本ページは Cookie を使用せず、アクセス解析ツールも利用していません。本ページは GitHub Pages で公開されており、ページの配信にあたり GitHub が IP アドレスなどの技術的情報を取得する場合があります。詳細は GitHub のプライバシーステートメント をご確認ください。

8. Google API Services User Data Policy への準拠

Orca Bot による Google API から取得した情報の利用および他のアプリへの転送は、 Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。

9. 本ポリシーの変更

本ツールの機能追加や法令の変更などに伴い、本プライバシーポリシーを改定する場合があります。重要な変更を行う場合は、本ページ上で告知します。 改定後のポリシーは、本ページに掲載した時点から効力を生じるものとします。

English Summary

This is a Japanese-language policy; the Japanese text is authoritative and this English summary is provided for reference only.

  • Data collected: Google account information, Gmail messages and metadata (subject, body, senders, recipients, dates, labels, thread and attachment metadata), OAuth tokens, and execution logs.
  • Purpose: to read, summarize, classify and organize email, to send notifications, and to maintain and improve the tool.
  • Third parties: message content may be sent to a third-party AI / large language model API (e.g. OpenAI) solely to perform the requested processing. Data is not sold, used for advertising, or shared with data brokers.
  • Retention: tokens and logs are kept only as long as necessary; message content is processed transiently and is not retained in a permanent mail database.
  • Your choices: you can revoke access at any time from Google Account permissions, or contact us to request deletion.

Orca Bot's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
